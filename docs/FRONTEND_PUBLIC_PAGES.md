# Frontend Public Pages

## 首页

默认首页使用 D“请求遥测实景”方案。页面固定为一屏，通过原生 Canvas 2D 数据流和本地技术实景图片呈现请求从接入到计量的完整链路，不新增前端运行依赖。

- Core、Route、Code、Meter 四个阶段分别展示请求接入、智能路由、协议执行和用量结算；滚轮、阶段按钮和鼠标视差会同步切换文案、颜色、背景与数据流形态，页面本身不滚动。
- 桌面、手机竖屏和手机横屏使用独立响应式布局；系统启用“减少动态效果”时，Canvas 降为静态帧并关闭持续运动。
- 页面读取后台“站点设置”中的站点名称、经安全过滤的 Logo、站点副标题、API Base URL、联系方式和文档链接；空值不会占用首屏空间。
- 自定义菜单只展示 `visibility=user` 的项目并按 `sort_order` 排序。宽屏直接显示前两项，其余项目进入折叠菜单；受限桌面、手机竖屏和手机横屏统一使用折叠菜单。
- 导航保留 `/models`、文档、语言切换、登录与控制台入口；API 地址和联系方式以纯文本元信息显示，不推断为链接或操作。
- 未登录用户的主操作进入 `/login`；普通用户进入 `/dashboard`；管理员进入 `/admin/dashboard`。
- 中文和英文环境分别使用对应首页文案。四张阶段背景位于 `frontend/src/assets/home/telemetry/`，运行时不依赖远程图片服务。
- 请求 ID、路由、延迟、Tokens 和费用属于四阶段视觉叙事数据，不代表后端实时运行统计。
- 管理员配置的 `home_content` 始终优先于 D 默认首页：HTTP(S) 地址继续使用全屏 iframe，其他内容继续按管理员 HTML 展示。

## 模型列表页

`/models` 是公开展示页，数据来自前端 `useModelWhitelist.ts` 中维护的模型集合。页面提供：

- 平台分组筛选。
- 模型名称搜索。
- 模型类型标签，用于快速区分 chat、fast、reasoning、coding、multimodal。

注意：该页面只展示前端内置模型集合，不代表某个用户或账号当前一定可用；实际可用性仍由渠道、账号池、模型映射和后端配置决定。
